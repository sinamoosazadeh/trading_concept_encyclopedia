# Evidence and source policy

## Separate term definitions from performance claims

A source may support that a term is used in a certain way without supporting that it predicts future returns. Each claim must state exactly what the cited source supports.

## Source hierarchy

Record source type rather than treating the hierarchy as absolute:

1. **Primary data or artifact:** data, code, original study, exchange specification, or documented experiment directly relevant to the claim.
2. **Peer-reviewed or formal research:** methods and findings subject to scholarly review, with the study design assessed on its merits.
3. **Technical documentation or specialist book:** useful for definitions and established procedures; claims still require contextual evaluation.
4. **Secondary analysis:** interpretation or review that should be traced to underlying evidence where possible.
5. **Practitioner material or informal discussion:** potentially useful for vocabulary, hypothesis generation, and discovering disputed usage, but not by itself proof of an edge.

A primary source is not automatically unbiased or methodologically sound. Assess relevance, quality, and limitations.

## Required source metadata

Capture a stable source ID, title, creator if known, publication date if known, source type, URL or persistent identifier where available, access date for web sources, and a brief relevance/limitation note. Preserve original publication details and distinguish them from the date the source was accessed.

## Claim status

- **unreviewed:** not yet evaluated.
- **supported:** available evidence supports the narrowly stated claim within its documented scope.
- **contested:** credible evidence or definitions conflict.
- **unsupported:** review did not find adequate support; this is not necessarily proof that a claim is false.

Confidence labels are editorial summaries, not calibrated probabilities. Avoid numerical confidence unless the method supports it.

## Citation integrity

Never fabricate a citation, URL, author, publication date, sample size, quote, or result. Do not cite a source merely because it mentions the same keyword. Record whether the source is direct evidence, contextual background, or evidence against the claim.

## Conflicts and uncertainty

Where sources disagree, retain the disagreement and explain differences in instruments, periods, definitions, methodology, or assumptions. Do not resolve disagreement by silently selecting the preferred interpretation.
