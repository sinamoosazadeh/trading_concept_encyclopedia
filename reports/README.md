# Generated reports

Files in this directory are derived snapshots, not canonical records.

- Run `python scripts/build_report.py` to produce `registry_report.json`.
- Do not hand-edit generated reports; change the input records or generator instead.
- Report metadata counts are not a measurement of research quality, completeness of the trading domain, source quality, or profitability.
- Reports should identify their version, generation time or reproducible inputs, and known counting limitations when those fields are added to the report contract.
